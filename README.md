# River Medlock Fe Science Communication Website

This project is a public-facing science communication website designed to explain iron (Fe) patterns in River Medlock macroinvertebrate data.

The website uses maps, charts, plain-language explanations, and interactive filters to help residents, students, and community groups understand how river organisms can be used to communicate environmental information.

## Project purpose

The aim of this website is not to present a traditional scientific report, but to communicate environmental data in an accessible and engaging way.

The website focuses on:

- River Medlock sampling locations
- Aquatic macroinvertebrates
- Iron concentration in organisms
- Seasonal and site-based comparisons
- Public understanding of river health

## Website features

- Interactive map of River Medlock locations
- Organism introduction cards
- Community composition chart
- Average Fe by site chart
- Average Fe by organism group chart
- Average Fe by season chart
- Interactive data explorer with filters
- Feedback section for evaluation
